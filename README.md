# Saee Patil

Personal research and machine learning portfolio built with Next.js.

## Local development

```bash
pnpm install
pnpm dev
```

## GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` builds a static export and deploys it whenever `main` is pushed.

In the GitHub repository, set **Settings > Pages > Source** to **GitHub Actions**. The deployed URL will be shown in the workflow summary.
